# Open Source Readiness

FusionPanel is open source under AGPL-3.0-only. The repository is intended to be public following the owner's authorization on 2026-11-01. Public availability does not establish production readiness, complete capability coverage or a security audit.

Product documentation describes FusionPanel's behavior, interfaces and modes. Preserve all applicable dependency/license/copyright notices. Use original or appropriately licensed code/assets; track dependencies and produce release provenance. Do not publish secrets, personal data, production inventories/dumps, private keys, authentication headers or unsanitized logs.

Before making the repository public, inspect tracked content and repository history for credentials/private artifacts, confirm the license and remove private operational identifiers from documentation. Synthetic fixtures must be clearly synthetic. A documented human/automated scan is risk reduction, not proof that a repository contains no possible secret.
