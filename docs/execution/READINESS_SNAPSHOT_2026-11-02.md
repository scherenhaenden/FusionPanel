## Evidence and calculation rules

- Feature gates: component / runtime integration / real E2E / closure, each 25 points; a partial component is 12.5. No new runtime/E2E/closure points are inferred from merges.
- Package gates: scope / implementation / unit evidence / real integration / E2E, each 20; a partial gate is 10. Open implementation artifacts receive at most 10 implementation points and no test credit without reviewed evidence.
- Existing qualified evidence is carried forward. New test counts are explicitly reported by the tracker, module README or W03, not rerun by this documentation update. BLOCKED, mocks, ignored and not-run cases receive no real integration/E2E credit.
- Remaining = 100 minus credited maturity. It expresses unmet evidence gates, not estimated engineering time. Full package closure still requires its explicit specification.
