## Evidence and calculation rules

Feature gates: component / runtime integration / real E2E / closure, 25 points each; partial component 12.5. Package gates: scope / implementation / unit evidence / real integration / E2E, 20 points each; partial artifact 10. Scores remain arithmetic means across every catalog row. New merged source receives partial artifact credit only where a previously absent artifact is now identifiable. Prior qualified/reported gates are carried forward; this refresh does not requalify historical evidence. No new runtime, executed-test, E2E or closure credit is awarded from PR claims, test source, mocks, skipped tests or successful returns after printing BLOCKED.

BLOCKED describes a missing prerequisite for a specific evidence lane. It does not discard the implementation or prevent publishing a bounded partial PR.
